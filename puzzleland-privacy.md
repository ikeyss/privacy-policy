# Política de Privacidade – Puzzleland

**Data de Vigência:** 05/11/2026

## 1. Coleta de Dados
- **Informações de uso:** Dados de gameplay (pontuações, progresso) são armazenados localmente via DataStore e enviados ao Google Play Games apenas com o consentimento do usuário.
- **Identificadores de dispositivo:** O app coleta apenas o ID da conta Google (para serviços Play Games) quando o usuário faz login.
- **Publicidade:** Utilizamos o Google Mobile Ads SDK; a coleta de IDFA/AAID segue a política de anúncios do Google.

## 2. Uso dos Dados
- Melhorar a experiência de jogo e oferecer placares de líderes.  
- Personalizar anúncios conforme a política de anúncios do Google.  
- Não vendemos ou compartilhamos dados pessoais com terceiros.

## 3. Compartilhamento de Dados
- **Google Play Games:** Dados de pontuação e conquistas são enviados ao serviço da Google.  
- **Firebase Analytics (se ativado):** Dados de uso anônimos são enviados ao Firebase.

## 4. Retenção
- Dados de gameplay são mantidos até que o usuário desinstale o app.  
- Dados de anúncios e analytics são retidos conforme as políticas do Google.

## 5. Segurança
- Todos os dados em trânsito são transmitidos por HTTPS.  
- Armazenamento local utiliza `EncryptedDataStore` para proteger informações sensíveis.

## 6. Direitos do Usuário
- O usuário pode excluir sua conta do Google Play Games a qualquer momento nas configurações da conta Google.  
- Para solicitar exclusão de dados, envie‑e‑mail para `ikeys3d@gmail.com`.
